Generative AI Showcase

What genAI can do—and how this page was built with it

What is Generative AI?

Generative AI (genAI) creates new content—text, code, images, and more—from patterns learned from data. Instead of only classifying or recognizing, it produces new outputs from prompts. This page was designed and written with genAI, and features an animated black cat drawn and animated with CSS.

Capabilities of GenAI

Text & language

Understand and generate natural language for chat, writing, and translation.

Code generation

Write and refactor code from descriptions, speeding up development.

Creative content

Assist with images, music, and design from high-level ideas.

Analysis & reasoning

Summarize data, answer questions, and help with decision-making.
