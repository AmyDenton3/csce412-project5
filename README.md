# Amy Denton's Portfolio Website

This is my personal portfolio website where I put together all the stuff I’ve worked on in computer science, product engineering, QA, and research.  

I built it using HTML, CSS, and JavaScript. There are two styles you can switch between with a toggle button—same pages.



## Pages

- **Home (index.html)** – My landing page, has my picture and an intro/about me.  
- **Portfolio (portfolio.html)** – Shows my projects and work experience, like Otty.AI, AuditBoard, TeleScan, and research.  
- **Qualifications (qualifications.html)** – Resume, skills, certifications, and education.  
- **Service (service.html)** – Volunteer and community work, like Tian Lab, BUILD TAMU, and LilyPad.  
- **AI Showcase (genai.html)** – A page I made about Generative AI using AI tools.  



## Styles

- **Style 1 (style1.css)** – Simple blue and white look. Inspired by some of the products I’ve worked on.  
- **Style 2 (style2.css)** – Pale green sidebar layout. Navigation is on the left and the whole page feels more modern/casual.  

You can toggle between them with the button at the top.



## Tech

- **Languages:** HTML, CSS, JavaScript  
- **Features:**  
  - Toggle between two different styles  
  - Embedded PDFs (resume and AWS cert)  
  - Navigation links to pages and external sites  
  - Links to projects and resources
